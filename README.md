# AuditCheck

Protótipo acadêmico de autoavaliação de segurança da informação para o Projeto 5. O questionário usa um recorte de 12 controles e requisitos da ISO/IEC 27001:2022 e da LGPD. O resultado tem finalidade diagnóstica.

## Como executar

Baixe ou clone este repositório e abra `index.html` em um navegador moderno. O app funciona com HTML, CSS e JavaScript, sem instalação ou servidor.

## Como demonstrar

1. Abra a **Visão geral** para ver a avaliação fictícia.
2. No **Questionário**, altere uma resposta e confira o recálculo do score e dos achados.
3. No **Plano PDCA**, atribua responsáveis e prazos e registre as etapas concluídas.
4. Em **Relatório**, clique em **Gerar PDF** e selecione **Salvar como PDF** na janela de impressão.

Em **Organização**, é possível iniciar uma avaliação em branco e definir o próprio escopo. O navegador armazena o cadastro, as respostas, as evidências simuladas e o plano localmente. A tela **Metodologia** explica pesos, faixas de maturidade e critérios de prioridade.
